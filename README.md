> A Wi-Fi router that fakes its own death, lights out and all, whenever a neighbour knocks to ask for the password again.

One sentence, 119 characters, pitching a ridiculous invention that fixes a tiny everyday annoyance: the neighbour who keeps asking for your Wi-Fi password. The router solves it by playing dead — lights out, no network, nothing to share.

## Run it

```sh
python3 main.py
```

Writes the pitch to `/output/entry.txt`. Pure Python stdlib, no network, fully deterministic.
